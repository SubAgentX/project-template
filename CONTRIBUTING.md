# Contributing

Thanks for taking the time to contribute!

## Getting started

1. Fork and clone the repository.
2. Install dependencies (see the README for the exact command).
3. Create a branch: `git checkout -b feature/short-description`.

## Making changes

- Keep changes focused — one logical change per pull request.
- Follow the existing code style (see `.editorconfig`).
- Add or update tests for anything you change.
- Update documentation when behavior changes.

## Commit messages

Write clear, imperative commit messages, e.g. `Add input validation to login form`.

## Pull requests

- Describe *what* changed and *why*.
- Link any related issues.
- Make sure tests and linters pass before requesting review.
